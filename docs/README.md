# Docs

- `SamathaScope_LLM_Context_v0.5.md` - current context pack for external LLM use, including the frontal-state classifier, dashboard/settings UX, shared feedback source model, and calibration flow.
- `samatha_score_methodology.md` - technical explanation of the current frontal-state feedback pipeline, clean calibration, optional artefact capture, smoothing rules, plotting, and recording semantics.
- `samatha_theravada_context.md` - practical Theravada framing, terminology caveats, and source links.

Historical note:

- `v0.3` and earlier docs described the retired RAI/Samatha-score pipeline.
- `v0.4` introduced the frontal-state classifier.
- `v0.5` keeps that classifier and adds the dashboard-first UI, shared-source model, guided calibration phases, and optional artefact capture.

Toolchain note (2026): this project targets AGP 8.13.2 + Gradle 8.13 + Kotlin 2.3.10 + Compose Compiler Gradle plugin.
